2. Follow [QUICKSTART.md](QUICKSTART.md) to run the app.
3. Read [PRODUCTION_ARCHITECTURE_REVIEW.md](PRODUCTION_ARCHITECTURE_REVIEW.md) for the current engineering priorities.
4. Read [FEATURE_EXPANSION_ROADMAP.md](FEATURE_EXPANSION_ROADMAP.md) when planning product work.
5. Use [DEPLOYMENT.md](DEPLOYMENT.md) only after the production blockers are resolved and the release configuration has been verified.
