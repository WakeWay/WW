# Assets Directory

This directory contains app resources like images and audio files.

## Required Audio Files

To enable alarm notifications with sound, add the following file:

- **alarm.mp3** - Alarm notification sound (place in this directory)

If not present, the app will still work with vibration and visual notifications.

## Image Files

The current placeholders are minimal 1x1 pixel images. For production, replace with:

- **icon.png** - App icon (recommended: 1024x1024px or larger)
- **splash.png** - Splash screen (recommended: 1024x1024px)
- **adaptive-icon.png** - Android adaptive icon (recommended: 1024x1024px)
- **favicon.png** - Web favicon (recommended: 192x192px or larger)
